# Utility coverage: 50 percent

Approved rule update, 2026-10-18: the shared footprint coverage threshold is 50%, inclusive. Tile centres inside any functioning provider zone count once. This applies consistently to required Oxygen/Electricity coverage, worker safety, construction, scavenging and bot placement decisions. Capacity, staffing, health and operating exemptions remain unchanged. Historical source documents and the older PDF guide remain reference editions; the HTML guide and runtime settings reflect this override.

All supported building-era prototype configurations use the new threshold, so existing saves receive it after restarting the player server, admin tools and bots. No save reset or database migration is needed. Configuration is cached per process. Tests were updated/added but not run.
