# Bot strategy v8

Bot-only planning changes, 2026-10-18. No player rules, prices, utility geometry, combat formulas or database schema change. Actions still go through ordinary player HTTP endpoints; snapshots and public targets retain existing visibility limits. Decision traces identify policy_version=strategy-v8.

- Scavenging leaves one healthy idle home citizen available; scavenger personalities leave two to allow their expedition policy to operate. Existing assigned jobs are not cancelled wholesale. The existing normal release action can free a scavenger for a concrete project/essential action. This reserve stops the last idle citizen immediately being reassigned to scavenging.
- Once Food/Water deficits are handled, Town Hall 2 is the first optional progression goal. Optional military procurement through the top-level policy waits until level 2 or the first upgrade is already paid and underway. Existing ready hardware may still fight at level 1 under normal combat requirements. Direct military component planners retain their reusable behavior.
- Combat prefers an existing eligible war over new declarations. If an otherwise eligible target has an unexpired war warning, bots wait instead of adding another declaration. Defensive personalities still do not initiate raids. The existing randomized personality weights, target shuffle, equipment quotas and expedition profiles remain.
- With no safe uncleared ruin, no ongoing building project and an idle worker, the bot considers reachable self-starting, unstaffed Oxygen providers. It checks actual tile-centre union geometry and collisions and chooses a position that makes at least one specific ruin safe. It buys missing inputs or submits an ordinary build action. Construction still needs workers and time; an imagined completed provider is used only for geometry prediction, never to grant present utility capacity or loot.

Five new strategy cases plus two combat follow-through cases were added. Existing audit version assertions and one focused production-upgrade test's mocks were updated for the new planning layer. Full runner discovery includes new Python tests automatically. No tests have been run; staged Python syntax and existing test-method retention were checked statically. Actual behavior and performance need the user's test run and bot observation.

Restart run_bots.py with the same database and URL after installation. Player server needs no restart for this bot-only change. Restart admin_suite.py only to refresh its behavior coverage text. Existing accounts, equipment, orders and histories are retained. Banking/private trades/diplomacy automation and other previously deferred bot behavior remain deferred.
